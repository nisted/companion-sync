Companion Sync

Share one Bitfocus Companion config between all your rigs: Windows, Mac and Raspberry Pi.

Download

What it does

  • Keeps one Companion config in a storage you choose: Google Drive, GitHub, Dropbox, OneDrive, a network folder or iCloud Drive.
  • One rig has the config at a time. It saves automatically every 15 minutes and hands the config back when Companion is quit.
  • Before taking the config, each rig keeps a safety copy of its own, so nothing is thrown away.
  • Optional encryption with a passphrase you choose.
